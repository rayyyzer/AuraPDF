Redesign the current AuraPDF design with one major objective:

**Make AuraPDF feel like a polished, premium DESKTOP APPLICATION — not a website.**

The current design feels too much like a web dashboard/landing page. Completely change that direction.

Do not create a marketing website aesthetic.

Do not use large hero sections, oversized headings, promotional cards, excessive whitespace, or webpage-style sections.

AuraPDF should feel like an application that a user opens every day to work with PDFs.

Think in terms of the quality and usability of a modern professional desktop application such as a premium document editor, productivity app, or creative tool.

---

# CORE DESIGN DIRECTION

Make the interface:

- Clean
- Compact
- Sophisticated
- Functional
- Calm
- Dense where appropriate
- Highly organized
- Minimal
- Premium
- Desktop-first
- Tool-oriented

The interface should prioritize the user's documents and workspace rather than decorative UI.

The application should feel like:

**"I am inside my PDF workspace."**

Not:

**"I am visiting a website about PDFs."**

---

# REMOVE AURA AI

Completely remove the concept/name **"Aura AI"**.

There is no separate AI product or AI-branded assistant.

The product is simply:

**AuraPDF**

AI capabilities should be integrated naturally into the application.

Use terminology such as:

- Ask
- Summarize
- Explain
- Extract
- Rewrite
- Translate
- Compare
- Insights
- Analyze

Do not call any of these features "Aura AI."

Do not create a separate AI brand identity.

AI should feel like a native capability of AuraPDF.

# APPLICATION SHELL

Make the entire application feel like a real desktop app.

Use a persistent application shell.

### Left sidebar

Include:

- AuraPDF logo
- Home
- Documents
- Recent
- Favorites
- Folders
- Settings

Keep the sidebar relatively narrow.

Do not make it look like a website navigation menu.

# HOME SCREEN

Do NOT create:

- Hero sections
- Giant welcome text
- Marketing copy
- Large promotional banners
- Huge empty areas

Instead create a compact workspace.

At the top:

- Page title
- Search
- Upload/New button
- Useful account/app controls

Main content:

### Recent

Show recently opened documents in a clean list/grid.

Show pinned documents.

### Quick actions

Keep these compact:

This should be the most important part of the application.

Design AuraPDF around the PDF itself.

Keep it compact.

Include:

- Search

- Fullscreen
- More

### Right contextual panel

Allow the user to open contextual tools such as:

- Document insights

- Extract
- Explain

# AI AS A NATIVE TOOL

AI should NOT appear as a giant chatbot occupying the interface.

Instead, make AI contextual.

For example:

When the user opens a PDF, provide subtle actions:

**Summarize · Ask · Explain · Extract**

When the user selects text, show a small contextual toolbar:

**Ask · Explain · Summarize · Rewrite · Translate · Copy**

When the user chooses Ask, open a compact contextual panel.

The AI interface should feel like a tool belonging to the PDF editor.

It should never feel like a separate chatbot application.

# OVERALL FEEL

The final design should feel like a product users could install and use for hours every day.

It should feel closer to a premium desktop productivity application than a SaaS marketing website.

The visual hierarchy should communicate:

**Documents first. Tools second. Decoration last.**

AuraPDF should feel:

**Quietly premium. Extremely polished. Efficient. Intelligent. Focused.**

Do not overdesign it.

Do not make it flashy.

Do not make it look like a generic AI startup.

Do not make it look like Adobe Acrobat either.

Create a distinctive AuraPDF identity while maintaining the usability expectations of a professional PDF application.

Most importantly:

**Redesign the existing concept rather than simply applying cosmetic changes.**

If a layout currently feels like a webpage, replace the layout.

If a component feels like a marketing card, replace it with an application-oriented component.

The final result should immediately communicate:

**"This is a real application for working with PDFs."**
